# 2026-06-01 Fix 1.21 CompoundTag Optional Build Failure

## Prompt Provided

```text
For the 1.21, your changes appear to have broken the build.
```

## Build Failure

```text
variants/forge-1.21.11/src/main/java/com/akitaattribute/essencethief/api/EssenceColorData.java:39: error: incompatible types: Optional<Integer> cannot be converted to int
    return Optional.of(EssenceColor.fromRgb(data.getInt(COLOR_NBT_KEY)));
```

## Proposed Solution Implemented

- Updated only the 1.21.11 variant of `EssenceColorData`.
- `CompoundTag#getInt(String)` is treated as returning `Optional<Integer>` in the 1.21.11 toolchain.
- Replaced the 1.20-style primitive `int` usage with Optional mapping:

```java
return data.getInt(COLOR_NBT_KEY).map(EssenceColor::fromRgb);
```

- Left the 1.20.x root implementation unchanged because that version expects primitive NBT getter behavior.
