# 2026-06-02 Fix 1.21 Targeted Particle sendParticles Signature

## Prompt Provided

```text
1.21 build failed. Please be sure to implement it correctly in both versions.
```

## Build Failure

```text
variants/forge-1.21.11/src/main/java/com/akitaattribute/essencethief/trail/EntityTrailManager.java:134: error: no suitable method found for sendParticles(ServerPlayer,T#1,boolean,double,double,double,int,double,double,double,double)
```

## Cause

The targeted particle helper was implemented with the 1.20.x `ServerLevel#sendParticles(ServerPlayer, ParticleOptions, boolean, ...)` overload. The 1.21.11 API requires an additional boolean parameter for the per-player overload:

```text
sendParticles(ServerPlayer, ParticleOptions, boolean, boolean, double, double, double, int, double, double, double, double)
```

The root 1.20.x build and the 1.21.x variant therefore need different helper implementations.

## Proposed Solution Implemented

- Left the 1.20.x root helper on the working 1.20.x signature:

```java
level.sendParticles(player, particle, true, x, y, z, count, xOffset, yOffset, zOffset, speed);
```

- Updated only the 1.21.x helper to use the 1.21.11 signature shown by the compiler:

```java
level.sendParticles(player, particle, true, true, x, y, z, count, xOffset, yOffset, zOffset, speed);
```

- Kept the targeted-player behavior intact:
  - `targetPlayers == null` sends to all players in the level.
  - A supplied player iterable sends only to those players.
- Kept dust particles and position-stepped upward movement unchanged.
- Bumped `mod_version` to `0.2.11` in both Gradle property files.
